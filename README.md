# 蜘蛛纸牌

一个使用原生 HTML、CSS 和 JavaScript 编写的单文件蜘蛛纸牌游戏。项目无需安装依赖，直接在浏览器中打开 `spider-solitaire.html` 即可游玩。

## 功能特点

- 支持 1 花色、2 花色、4 花色三种难度。
- 支持鼠标拖拽和移动端触摸拖拽。
- 内置分数、步数和计时统计。
- 支持撤销上一步操作。
- 待发牌区和已收集牌区固定在页面底部，便于查看剩余发牌组数和完成进度。
- 卡牌使用响应式尺寸，在桌面和移动端都会自动适配。
- 自定义深色牌背、发牌动画和收牌动画。
- 完成 K 到 A 的同花色序列后，会自动收集并计分。
- 所有列都有牌时才能从待发牌区继续发牌。

## 运行方式

直接用浏览器打开：

```text
spider-solitaire.html
```

也可以在本地项目目录中双击该文件打开。项目不需要构建工具、包管理器或后端服务。

## 玩法说明

1. 进入页面后选择难度：
   - 简单：1 花色
   - 中等：2 花色
   - 困难：4 花色
2. 拖动可移动的同花色递减牌组。
3. 目标列为空，或目标列顶牌点数正好比拖动牌组首牌大 1 时，可以移动。
4. 当某一列底部形成同花色 `K` 到 `A` 的完整序列时，该组牌会自动收集到底部完成区。
5. 完成 8 组完整序列后获胜。

## 操作说明

- 拖拽牌：移动单张牌或同花色递减牌组。
- 点击待发牌区：向 10 列各发 1 张牌。
- 撤销：恢复上一步移动或发牌前的状态。
- 新游戏：返回难度选择界面。

## 项目结构

```text
.
├── README.md
└── spider-solitaire.html
```

核心逻辑、样式和页面结构都在 `spider-solitaire.html` 中：

- CSS：页面布局、卡牌视觉、响应式规则、发牌和收牌动画。
- HTML：开始界面、游戏界面、底部控制区、胜利弹窗。
- JavaScript：洗牌、发牌、拖拽、移动校验、撤销、计分、计时和胜利判断。

## 技术说明

- 纯前端实现，无第三方依赖。
- 使用 CSS 变量统一控制卡牌尺寸、堆叠间距和响应式比例。
- 使用 DOM 重渲染同步游戏状态。
- 使用对象标记 `_dealing`、`_collecting` 等临时状态驱动动画。

## 浏览器兼容性

建议使用最新版 Chrome、Edge、Safari 或 Firefox。移动端浏览器支持触摸操作，但小屏幕上牌桌会根据宽度自动缩放和横向适配。
