# 蜘蛛纸牌

一个纯 HTML、CSS、JavaScript 实现的单文件蜘蛛纸牌小游戏，打开浏览器即可游玩，无需安装依赖。

## 功能特点

- 支持 1 花色、2 花色、4 花色三种难度
- 支持拖拽移动卡牌
- 支持提示、撤销、发牌
- 内置计分、步数统计和计时器
- 包含胜利动画与音效开关
- 适配桌面端和移动端屏幕

## 运行方式

1. 直接用浏览器打开 `spider-solitaire.html`
2. 选择难度后开始游戏

也可以在当前目录启动一个静态服务器后访问，例如：

```bash
python3 -m http.server 8000
```

然后打开 `http://localhost:8000/spider-solitaire.html`

## 文件说明

- `spider-solitaire.html`：游戏主文件

## 操作说明

- 拖动已翻开的有效牌组到目标列
- 点击底部发牌区可继续发牌
- 点击“提示”查看推荐移动
- 点击“撤销”回退上一步
